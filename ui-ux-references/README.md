# SerbisYO UI/UX References

This folder stores the visual references used during SerbisYO implementation.

Use the prompt IDs from `UI_IMAGE_PROMPTS_MASTER.md` when naming approved/generated screens so developers can immediately trace each image back to its design prompt.

Each major page/state has its **own titled folder**, and inside that folder are exactly two platform subfolders:

```text
01 - Explore Home/
├─ desktop/
└─ mobile/
```

Recommended naming examples:

- `01 - Explore Home/desktop/P01-explore-home-desktop.png`
- `01 - Explore Home/mobile/P02-explore-home-mobile.png`
- `02 - Service Profile/desktop/P03-service-profile-desktop.png`
- `02 - Service Profile/mobile/P04-service-profile-mobile.png`
- `07 - Contribution Workflow Board/desktop/P11-contribution-workflow-desktop.png`
- `07 - Contribution Workflow Board/mobile/P12-contribution-workflow-mobile.png`
